## 2. 範圍與裁定

### 元件樹（照設計稿 §3）
```
TodayPage（/today；今日任務與待補清單各自 GET）
├─ TodayTaskSection（TaskListOut；完成動作容器）
│  ├─ TodayTaskRow（純展示：標題/日期/狀態/事前星數摘要）
│  └─ CompleteTaskAction（POST /tasks/{id}/complete；版本、錯誤、成功後回報入口）
├─ PendingFeedbackSection（GET /feedback/pending）
│  └─ PendingFeedbackRow（純展示；只用契約欄位；連 /tasks/:taskId/feedback）
└─ TodayErrorRegion（兩個 GET 各自保留錯誤）

TaskFeedbackPage（/tasks/:taskId/feedback）
├─ FeedbackTaskContext（純展示：TaskOut 的 expected_stars/star_source＝事前預設脈絡；送出的 rubric_id 另取 active rubric，非此處）
├─ 未填→ FeedbackForm（星數/精力初值皆空、不預填；invest_vs_expected 選填）
├─ 已填→ CurrentFeedbackCard（唯讀顯示 FeedbackOut）＋「修改功能尚未開放」
└─ FeedbackActions（保存／稍後；ErrorBanner）
```

### 關鍵裁定（照設計稿 §6）
- **今日範圍（裁定 5）**：今日＝`status` 為 todo 或 doing 且 due≤**伺服器今天**（`/meta/today`），**含逾期**；分「逾期／今日」兩組、排除 done。`due_before` 是上界，前端從 GET /tasks 結果排除 done。不用瀏覽器時鐘。
- **完成（裁定 6）**：送 `expected_version`（當前 TaskOut.version）；**預設不露完成日控制、省略 `done_date` 由後端取今天**；要補記過去日才展開 DatePicker 明選。成功回 `feedback_required`：true 才引導回報／稍後。`STALE_VERSION` 重讀清輸入、由人重做、不自動重送。
- **回報建立（裁定 1）**：`actual_stars`(1–5)／`energy`(high/mid/low) **初值空、不預選、不從 expected_stars 複製**；`invest_vs_expected` 選填不預選；**`rubric_id` 帶開啟面板時由 `GET /rubrics?active=true` 擷取並鎖定的目前量表 id（非 TaskOut.rubric_id）**。缺必填停在表單、保留輸入、不送 PUT；後端 422／非 done 由 ErrorBanner 顯示。`overdue_days` 不送、前端不算，收到原樣顯示。
- **goal_id（裁定 2）**：PUT **不帶 goal_id**（目標關聯走 12.12 /goal-links）；回報頁不設目標入口。
- **修改（裁定 3，本票調整）**：已回報→讀 `GET /tasks/{id}/feedback` 顯示唯讀卡＋「修改功能尚未開放」；**不做可寫更正面板（延 9.3）**。歷程連結保留。不從 `EventOut.extra` 猜現值。
- **稍後補（裁定 1）**：僅關閉/返回，**不送空白 PUT、不取消 done**；任務維持 done、列在待補清單；完成回報統計不計入該任務。
- **導向與失效（裁定 4）**：完成動作後留今日頁、給回報/稍後入口；保存回報後回今日頁並刷新待補。**PUT 成功失效 tasks＋timeManagement＋feedbackPending；complete 成功另失效 gantt**。集中於 `queryKeys.ts`／失效表（沿 #55 共用層），不在頁面自造鍵；新增 `keys.feedbackPending(...)`。
- **三態**：今日任務與待補清單各自 loading／error／empty；GET 失敗不轉成「今天沒任務／沒待補」，用區域 ErrorBanner；深連結先讀 TaskOut、讀取中不顯示可送的空回報。

### 契約（全用重生成型別）
- `GET /meta/today → {today}`（伺服器今天）
- `GET /tasks?due_before=&status=&…→ TaskListOut`（既有）
- `POST /tasks/{id}/complete → CompleteOut{task,event,feedback_required}`（既有）
- `PUT /tasks/{id}/feedback`（`FeedbackSave`：actual_stars／energy／invest_vs_expected?／**rubric_id**）→ **201** `FeedbackSaveOut{feedback,event}`；已回報→**409 `FEEDBACK_EXISTS`**；非 done／缺欄／rubric 不存在→422
- `GET /tasks/{id}/feedback → FeedbackOut`（未填→404）
- `GET /feedback/pending → PendingFeedbackOut{items,total}`

### 界線
- **不做更正/修改寫入（9.3）、不做 AI-02 預設星數（9.11）**。
- 不帶 goal_id、不設目標選擇器。
- 不改後端／Dev-A 元件；不把 GET /tasks 的 done 清單當待補；不從瀏覽器時鐘取今天/完成日。
- 12.3 任務詳情的「完成回報顯示區」另票接線，不在本票。
