## 一、對外契約（唯讀使用，spec 5.13）
| Method | Path | 說明 |
|---|---|---|
| POST | `/goals/{id}/report/draft` | 產生 AI-04 草稿，**不帶 body** |
| GET | `/goals/{id}/report` | 取得既有回報（不產生） |
| PUT | `/goals/{id}/report/manual` | 儲存人工版 |

**三端點輸出相同**（`GoalReportOut`）：
```json
{ "id": 9, "goal_id": 2, "ai_status": "ok", "excluded_private": 1,
  "draft": "…", "validated": true, "manual_text": null, "updated_at": "2026-11-20T10:00:00+08:00" }
```
- `GET`：404 `NOT_FOUND`、`details` 只放 `goal_id` ＝**尚未產生**，顯示空狀態、**不顯示錯誤橫幅**（比照 5.14）。
- `POST …/draft`：產生草稿。`linked=0` → `ai_status="unavailable"`、`validated=false`；AI 失敗時保留上次成功初稿、回應仍是退路。封存目標也可產生。
- `PUT …/manual`：輸入 `{ "manual_text": "…" }`。**不帶 `expected_version`、後寫蓋先寫**（無 STALE_VERSION）；可為 null 或空字串（清除）；超過 20,000 字回 **413 `PAYLOAD_TOO_LARGE`**；含 NUL 回 `VALIDATION_ERROR`；內容相同照常儲存。
- `validated=false` 時 `draft=null`，前端改用既有 `GET /goals/{id}/stats`（`GoalStatsOut`，階段 1 已做）顯示統計表；**回應不重複附統計**。
- `excluded_private` 是**件數**（私人任務排除數），`>0` 時顯示「已排除 N 件私人任務」。

## 二、元件與行為（GoalReportArea，掛在階段 1 目標頁每個目標詳情下）
**直接沿用你剛做的 12.13 週報頁（weeklyView / WeeklyReportColumns / ManualWeeklySection）的版型與互動**，只是換成目標回報端點：
1. AI 初稿欄 ‖ 人工版欄並列。
2. 產生初稿鈕 → `POST …/draft`；`ai_status='unavailable'` → 顯示 `AIFallback`，不報錯。
3. `validated=false`（或讀取重新對帳後數字對不上）→ **改顯示統計表**（`GET /goals/{id}/stats`）。
4. 人工版編輯框：`value=manual_text`（單一事實來源）；儲存 → `PUT …/manual`，**不帶 expected_version**；成功顯示提示。字數上限 20,000（可前端擋，或讓 413 回來顯示錯誤）。
5. 複製鈕：比照 12.13，複製人工版編輯框文字、空白停用、成功顯示「已複製」。不代發。
6. `excluded_private > 0` → 顯示「已排除 N 件私人任務」註記（FR-RPT-01）。
7. 404（尚未產生）→ 顯示「尚未產生回報」＋產生鈕，不顯示空錯誤。

> 無 STALE_VERSION 流程（人工版後寫蓋先寫）。STALE 只在階段 1 的 `POST /goal-links`，不在本票。

## 三、不可破原則
- 評價由使用者下：AI 只產 `draft`，使用者確認／改寫人工版才算數；前端不自動把 `draft` 當定稿、不自動送出。
- 確認前不入統計：統計表只讀已確認資料。
- 私人範圍排除在後端（`excluded_private`），前端只呈現。
