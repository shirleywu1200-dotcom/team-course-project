## 2. 契約（全用 #84 生成型別）
| 端點 | 型別 | 要點 |
| --- | --- | --- |
| `GET /goals?include_archived=` | → `GoalListOut` | **只有 `items`、無 `total`**（設計稿的 total 不採用） |
| `POST /goals` | `GoalCreate` → `GoalOut`(201) | type/title/period/energy_plan 必填；expectation 必帶未封存 project_id、target 忽略存 0（B4）；其他類型 project_id=null |
| `GET /goals/{id}` | → `GoalOut` | |
| `PATCH /goals/{id}` | `GoalPatch` → `GoalPatchOut` | type/project_id 不可改；只有實際變更才寫事件 |
| `POST /goals/{id}/archive` | → `GoalOut` | 封存仍可讀、可查統計、可編輯 |
| `GET /goals/{id}/stats` | → `GoalStatsOut`（含 `GoalProgress`） | progress：time=null（B3）、expectation=pct（B4）；`judgement`／`judgement_note` **原樣顯示、前端不重算、零樣本不補 0**（G2、DA-12） |
| `GET /goals/matrix` | → `GoalMatrixOut`（`items`） | **鍵為 `items`、非 `rows`** |
| `GET /goal-links/pending` | → `PendingLinkOut` | items 各含 task_id/title/project_id/scope/done_date/version；**不含 AI 建議**（G3） |
| `POST /goal-links` | `GoalLinkIn` → `TaskEventOut` | 輸入 `{task_id, goal_id, expected_version}`（`GoalLinkIn` 目前**無 ai_run_id**）；`STALE_VERSION` 一律重載由人重做（前端規範 5）；`NO_CHANGE` 不視為錯誤 |

## 3. 關鍵裁定
- **B1（暫定・PO 可改）**：建立任務帶 `goal_id` **不算**關聯決定 → pending 清單只看 `goal` 事件決定（照 Dev-A 暫定、spec 現行）。
- **B2（暫定・PO 可改）**：停用類型的既有目標**仍可讀／查統計／編輯**（比照專案封存 B7 pattern）；只有「新增」時才擋停用類型（`GoalTypeSummary` 依 `goal_types_enabled`）。
- **G1**：關聯一律帶 `expected_version`；單一事實來源為 `tasks.goal_id`（統計／矩陣／pending 都讀它）。
- **判讀／統計**：`judgement`／`judgement_note`／`progress`／`pct` 一律**逐字顯示、前端不重算、不補 0**。
- **AI 建議**：pending **不自動呼叫 AI**；`/goal-links/suggest`（AI-03）屬第三片，本票不接。
- **失效表**（集中 `queryKeys.ts`，依小工頭準備規劃）：`POST /goal-links` 成功失效 **tasks／goals／goalLinks／gantt／events**；建立／編輯／封存目標失效 **goals／events**。新增具體 key：`keys.goals()`／`goal(id)`／`goalStats(id)`／`goalMatrix()`／`goalLinksPending()`（接在 #84 已加的 `goals`／`goalLinks` 根下）。
- **三態**：各區 loading／error／empty 分離；GET 失敗不轉「沒有目標」，用既有 `ErrorBanner`、可重試、不自動重送；零樣本統計（avg null）照顯示。
