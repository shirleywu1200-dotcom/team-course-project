`history.sql`（全部虛構）：一個工作專案、一筆 `batches`、3 筆共用 `batch_id` 的 `due` 事件、2 筆不同類型的事件（`annotation`、`status`）、1 個單點任務及它的 `due` 事件。筆數控制在一頁內，分頁只斷言「下一頁」是停用的，不另外灌 100 筆以上的資料去測翻頁。

斷言原則（沿用前兩片）：畫面上看得到的用 `getByRole`／`getByLabel` 斷言；資料是否正確用 API 斷言，不直接查資料庫。
